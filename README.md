# 歐洲大型旅行資料庫

這是一個可部署到 GitHub Pages 的靜態網站，收錄歐洲旅行景點、自然景觀、城堡、博物館、教堂、溫泉、市場、餐廳、咖啡甜點、酒吧與地方特色店。

## 檔案

- `index.html`
- `assets/app.js`
- `assets/styles.css`
- `assets/places.json`
- `.github/workflows/pages.yml`

## 資料提醒

評分、評論數、營業時間與價格會變動，出發前請以 Google Maps 即時資訊為準。

## 部署

將此資料夾推到 GitHub repository 的 `main` 分支後，GitHub Actions 會透過 Pages workflow 部署靜態網站。
